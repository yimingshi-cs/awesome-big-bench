<a name="contribute-with-your-agent"></a>
## 补充评测，或纠正一条记录

[复制 PR 提示词](@@SITE@@#contribute)，发给 Codex、Claude Code 或其他编程助手。告诉它**要改哪个评测的哪个版本、改什么**，并附上能证明这处改动的论文段落、评分代码或官方发布说明。名字里没有「Bench」的评测也欢迎。

纠错时，在原条目上复制提示词会自带条目编号。助手核对来源、修改数据并提 PR，维护者审核后决定是否合并。也欢迎[手动投稿](CONTRIBUTING.md)。
