# Choosing a benchmark by task

Benchmarks in the same field can ask a model to do very different things. Start with these comparisons, or jump to the tables for inputs, expected outputs and scoring rules.

| If you care about… | What the model actually has to do |
|---|---|
| Writing code | [HumanEval](@@SITE@@#browse?entry=humaneval): finish a function. [SWE-bench](@@SITE@@#browse?entry=swe-bench): fix an issue in an existing repository. |
| Using a computer | [WebArena](@@SITE@@#browse?entry=webarena): complete a task on a website. [OSWorld](@@SITE@@#browse?entry=osworld): operate desktop applications. |
| Games | [Kaggle Game Arena](@@SITE@@#names?field=Embodied&prefix=Game&suffix=Arena): play an existing game against another model. [GameCraft-Bench](@@SITE@@#browse?entry=gamecraft-bench): build a playable game. |
| Remembering | [Needle in a Haystack](@@SITE@@#browse?entry=needle-in-a-haystack): retrieve a planted fact. [LongMemEval](@@SITE@@#browse?entry=longmemeval): answer from past conversations. |
| Doing research | [MLE-bench](@@SITE@@#browse?entry=mle-bench): make an ML competition submission. [PaperBench](@@SITE@@#browse?entry=paperbench): reproduce a published paper. |
