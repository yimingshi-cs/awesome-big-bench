# Third-party identification marks

These six first-party assets identify the named project or, where explicitly labelled, its publisher. This is a positive allowlist, **not** a list of logos that can be reused for other purposes. They are not endorsements, quality badges, project branding for this directory, or covered by the directory's MIT/CC BY license. No remote image requests are required. The `source`, `rights_url`, `credit_url`, license and per-file changes are recorded in [manifest.json](manifest.json).

## Display

- Use the **Artificial Analysis** symbol in its supplied purple, on a light, quiet background with clear space, beside the fully spelled-out index name. Link attribution to [Artificial Analysis](https://artificialanalysis.ai/). The [brand kit](https://artificialanalysis.ai/brand-kit) expressly allows official assets in materials subject to its usage guidelines. The publisher symbol is not a benchmark certification badge.
- Likewise, identify APEX-Agents’ publisher as **Mercor**, not an APEX-specific logo. Preserve the Mercor SVG's colors, proportions and internal safe area, per its [brand guidelines](https://www.mercor.com/brand/).
- [OSWorld](https://os-world.github.io/) supplies the keyboard-and-mouse graphic as its own site favicon. Its site-wide CC BY-SA 4.0 declaration and source URL are listed above. Attribute the OSWorld website and retain the attribution, adaptation and license links when redistributing the thumbnail.
- LIBERO and Toolathlon use **the actual published artwork** from the authors’ CC BY papers, not a software license assumed to extend to a project's identity. HELM is the project asset distributed with the Apache-licensed HELM frontend (including the packaged static build); [the full upstream notice](HELM-APACHE-2.0.txt) is retained. Display complete wordmarks at a readable width in details; do not squash them into square icons.
- A project homepage, an affiliation or a bare open-source license on unrelated software/data is not sufficient by itself. No university seals, ARC Prize Verified badges, inherited template icons or repurposed game artwork are included. A change of scope or branding needs a new review.
