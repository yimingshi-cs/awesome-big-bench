# Directory additions · 25 November 2026

A place in Featured is an editorial recommendation, not a badge for appearing in a
particular model release. We look for a distinct task with a public scoring protocol
and either independent adoption or a foundational role. We link the exact edition.
All entries preserves the historical inventory; it is not a ranked list.

| Entry | What it adds | Primary evidence and independent use |
|---|---|---|
| Spider 1.0 | Generalizing SQL generation to unseen schemas | [Original task and submitted systems](https://yale-lily.github.io/spider) · [DTS-SQL evaluation](https://aclanthology.org/2024.findings-emnlp.481/) |
| Spider 2.0-Lite | Enterprise-scale SQL in multiple dialects, not the full agent track | [Lite protocol](https://github.com/xlang-ai/Spider2/tree/main/spider2-lite) · [organizers’ Lite results and submitted systems](https://spider2-sql.github.io/) |
| WebVoyager | Goal completion on live websites, separate from its namesake agent | [Original benchmark](https://arxiv.org/abs/2401.13919) · [OpenAI Operator / CUA evaluation](https://openai.com/index/computer-using-agent/) |
| MTEB | Evaluating embedding vectors across downstream text tasks | [Original suite](https://arxiv.org/abs/2210.07316) · [OpenAI’s English-suite results](https://openai.com/index/new-embedding-models-and-api-updates/) |
| LibriSpeech | Audio transcription with standard clean/other test splits and word error rate | [Corpus](https://www.openslr.org/12/) · [wav2vec 2.0](https://arxiv.org/abs/2006.11477) · [2014 dated Kaldi recipe](https://github.com/kaldi-asr/kaldi/commit/f1d927200f146d2fa6af2395398fe6b86712d675) |
| OCRBench | Text reading and extraction from images; original edition | [Dated question set](https://github.com/Yuliang-Liu/MultimodalOCR/commit/15218c3a03dbbc74b5983be193699517f848f234) · [MiniCPM-V 2.6 evaluation](https://huggingface.co/openbmb/MiniCPM-V-2_6) |
