# Arena as a possible name-map ending

**23 November 2026 · design assessment, not a full search.** Four current prefixes have direct evidence:

| Existing prefix | Documented spelling | Original source |
|---|---|---|
| SWE | SWE Arena | [Project announcement](https://bigcomputer-project.github.io/blog/swe-arena.html) |
| Robo | RoboArena | [Project](https://robo-arena.github.io/) |
| Embodied | Embodied Arena | [Paper](https://arxiv.org/abs/2509.15273) |
| Video | Video-Arena | [Paper](https://arxiv.org/abs/2610.14158) |

This establishes that “Arena” is a useful naming pattern, not how the remaining names should be colored. Adding a column requires a dated decision for all 29 prefixes. It would not place Code Arena, WebDev Arena, WebArena or Chatbot Arena: none of Code, WebDev, Web or Chatbot is a current prefix. SWE Arena is not a substitute for WebDev Arena.

Keep scoring separate from spelling. [Code Arena’s WebDev track](https://arena.ai/blog/webdev-arena) ranks human preferences between generated apps. [WebArena](https://arxiv.org/abs/2307.13854) tests whether an agent completes an assigned task on a website. Include appropriate projects in the directory without changing a name verdict. Keep the current map unchanged until checks cover the proposed column.
