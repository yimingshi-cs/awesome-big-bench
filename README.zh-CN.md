## 漏了哪个评测？哪条写错了？

把下面这段贴给 Codex 或 Claude Code，再发给它一篇论文或一个官网链接就行。你自己做的评测也欢迎。

```text
帮我给这个 GitHub 仓库补评测或纠错：
yimingshi-cs/awesome-big-bench

先核对版本和原始出处。
不清楚我要改什么，或缺来源，就问我。
按 CONTRIBUTING.md 查重，
用论文或官方发布说明核对要改的内容。
更新中英文条目，重新生成文件，跑完检查。
从我的 fork 提 PR，写清改动和出处，
把 PR 链接发给我。
```
