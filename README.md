[HumanEval](https://yiming-shi.com/awesome-big-bench/#browse?entry=humaneval) asks the model to finish a function; [SWE-bench](https://yiming-shi.com/awesome-big-bench/#browse?entry=swe-bench) asks it to fix an issue in a real repository.

<a name="contribute-with-your-agent"></a>
## Add or correct an entry

[Copy the PR prompt](https://yiming-shi.com/awesome-big-bench/#contribute) into Codex, Claude Code or another coding agent. Name the benchmark and edition, say **what should change**, and link the paper section, scoring code or release note that supports it. A benchmark needn’t have “bench” in its name.

For a correction, copy the prompt on the entry itself to include its ID. Your agent checks the source, updates the data and opens a pull request for maintainer review. You can also [submit a PR yourself](CONTRIBUTING.md).
